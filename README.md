# Gapwise Mobile

Native iOS and Android client for [Gapwise](https://gapwise.ca), built with Expo and React Native.

## Goals

- Native-first iOS and Android experience for timetable, Today, gap planning, campus places and routing.
- Preserve Gapwise's guest-first, privacy-minimizing and data-integrity guarantees.
- Reuse the canonical Gapwise API/contracts rather than creating a second source of truth.
- Match the official Gapwise visual system and brand.
- Support cloud builds and phone-first QA through Expo/EAS and TestFlight/internal Android distribution.

## Canonical brand source

The official deer mark and design system are sourced from the main repository:

- `andrewmuratov/gapwise/public/logo-mark.svg`
- `andrewmuratov/gapwise/src/styles.css`

Do not redraw, approximate, or replace the official mark with a generated logo.

## Development

The project is being bootstrapped under the Linear project **Gapwise — Mobile**. Until the first Expo bootstrap PR lands, this repository intentionally contains only project metadata.
